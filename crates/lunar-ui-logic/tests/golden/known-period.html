Glossaire des termes présents

GOOSE · Liaison
Generic Object Oriented Substation Event (IEC 61850-8-1) : les événements d'un poste électrique (déclenchements, positions d'organes) publiés en multicast directement sur Ethernet (EtherType 0x88B8), souvent sous une étiquette VLAN, sans IP ni transport. Temps réel : quelques millisecondes exigées entre la détection et la réception.
VLAN (802.1Q) · Liaison
Réseau local virtuel : segmente un réseau physique en domaines de diffusion isolés. Marqué dans la trame par une étiquette 802.1Q portant l'identifiant de VLAN.
ICMPv6 · Réseau
Version IPv6 d'ICMP. Assure aussi la découverte de voisins (NDP), l'équivalent IPv6 de l'ARP.
QUIC · Transport
Transport moderne sur UDP, chiffré par défaut (TLS 1.3 intégré) et à faible latence. Base de HTTP/3.
HTTP · Application IT
HyperText Transfer Protocol : protocole du Web (port 80), requêtes/réponses en clair.
WireGuard · Application IT
Tunnel VPN moderne sur UDP (port 51820 par défaut) : quatre types de messages (initiation, réponse, cookie, données) à l'en-tête fixe. Tout le contenu est chiffré ; LUNAR ne voit que les pairs et le volume. Utilisé tel quel ou derrière Tailscale, Mullvad, NordVPN…
Tunnel / CAPWAP · Concept
Encapsulation d'un trafic dans un autre (ex. CAPWAP pour les bornes Wi-Fi). LUNAR décapsule et relie père/fils par un identifiant de tunnel.

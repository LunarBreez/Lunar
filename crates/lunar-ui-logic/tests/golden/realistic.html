Glossaire des termes présents

ARP · Liaison
Address Resolution Protocol : résout une adresse IPv4 en adresse MAC sur le réseau local (« qui a l'IP X ? »), par diffusion. Très bavard en broadcast.
VLAN (802.1Q) · Liaison
Réseau local virtuel : segmente un réseau physique en domaines de diffusion isolés. Marqué dans la trame par une étiquette 802.1Q portant l'identifiant de VLAN.
ICMP · Réseau
Internet Control Message Protocol : messages de contrôle et d'erreur d'IPv4 (ping, « destination inaccessible », etc.).
TCP · Transport
Transmission Control Protocol : transport fiable, orienté connexion, avec accusés de réception et remise ordonnée. Base de HTTP, TLS, etc.
DNS · Application IT
Domain Name System : traduit les noms de domaine en adresses IP (port 53), souvent en UDP.
mDNS · Application IT
Multicast DNS : résolution de noms sans serveur, en multicast local (224.0.0.251, port 5353). Base de Bonjour/AirPlay et de nombreux objets connectés.
SSDP / UPnP · Application IT
Découverte d'équipements UPnP en multicast (239.255.255.250, port 1900). Fréquent chez les objets grand public.
TLS / HTTPS · Application IT
Transport Layer Security : chiffre et authentifie une communication (successeur de SSL). HTTPS = HTTP sur TLS (port 443).
Modbus/TCP · Application OT/ICS
Protocole industriel très répandu (port 502) pour lire/écrire les registres d'un automate. Simple, sans authentification native.
S7comm · Application OT/ICS
Protocole propriétaire Siemens pour dialoguer avec les automates S7, transporté sur ISO-TSAP/COTP (port 102).
Tunnel / CAPWAP · Concept
Encapsulation d'un trafic dans un autre (ex. CAPWAP pour les bornes Wi-Fi). LUNAR décapsule et relie père/fils par un identifiant de tunnel.
